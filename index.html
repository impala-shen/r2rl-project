Replay and Reinforce:
Reusing One Demonstration to Learn Cross-Object Contact-Rich Manipulation

Chengyandan Shen, Wilbert Peter Empleo, Iñigo Iturrate

SDU Robotics, the Maersk Mc-Kinney Moller Institute

Paper Code

Overview

Collecting per Object Demonstration Data is Costly

Replay and Reinforce (R²RL) uses a single demonstration as a persistent source of action proposals during online reinforcement learning. At each step, an uncertainty-aware critic ensemble compares the replay action with the learned policy action. This allows the robot to reuse demonstrated behavior while learning adaptations through interaction.
